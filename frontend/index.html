How the System Works

The system predicts crop yield using trained machine learning models and climate-related variables such as rainfall, temperature, and agricultural input values. Users select crops, choose a country, and enter land size, after which the backend processes the request, generates prediction features, runs crop-specific models, and returns the result through charts, yield summaries, and AI-based recommendations.

Model Capability and Performance

Different machine learning algorithms were selected for different crops depending on which model produced the strongest prediction performance during testing. The coefficient of determination (R²) was used to evaluate how well each model explains crop yield variation.

Crop Selected Model Test R²
Maize Gradient Boosting 0.9080
Rice Gradient Boosting 0.9617
Wheat Random Forest 0.8157
Cassava Random Forest 0.6728
Sorghum Gradient Boosting 0.6067
Potatoes Ensemble Model 0.7841
Soybeans Ensemble Model 0.8524

In machine learning prediction systems, an R² value above 0.90 is generally considered very strong, values between 0.80 and 0.89 are considered strong, values between 0.60 and 0.79 are considered moderate, while values below 0.60 are considered weak. Based on the testing results, the developed models produced strong predictive performance for crops such as rice, maize, soybeans, wheat, and potatoes, while cassava and sorghum showed moderate prediction performance.
